## О проекте

Веб-приложение, в котором пользователь создаёт пространство со своими фильмами, критериями, участниками и алгоритмом расчёта. Фильмы оцениваются по критериям и сравниваются попарно, рейтинг считается тремя алгоритмами (Weighted score, Bayesian average, Elo), а для любого фильма можно посмотреть, из чего сложилось его место. Приложение рассчитано на зрителей, которые ведут личный рейтинг, и на группы: киноклубы, компании друзей, жюри конкурсов.
